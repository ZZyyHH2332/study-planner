# Note Templates Reference

## Overview

Four note types follow the Zettelkasten method, each with a specific frontmatter schema and role in the knowledge flow.

## Vault Structure

```
D:\UserData\Documents\Obsidian Vault\
├── 00_Inbox/          ← Fleeting Notes
├── 10_Sources/         ← Literature Notes
├── 20_Zettelkasten/    ← Permanent Notes (knowledge graph nodes)
├── 30_MOCs/            ← Maps of Content (learning domains)
├── 99_System/
│   ├── Templates/      ← 4 note templates
│   └── Attachments/
```

## 1. Fleeting Note

**Folder**: `00_Inbox/`
**Role**: Quick capture of ideas. Process within 1-2 days: promote to Permanent or discard.
**Learning metadata**: None

```yaml
---
id: "202608311430"              # Timestamp ID (YYYYMMDDHHmm)
tags:
  - inbox
  - fleeting
created: "2026-08-31"
status: unprocessed             # unprocessed → promoted | discarded
---
```

## 2. Literature Note

**Folder**: `10_Sources/`
**Role**: Source-bound summary. Record origin and key takeaways. Track knowledge flow via `inspired`.
**Learning metadata**: type, author, url, inspired

```yaml
---
id: "202608311431"
tags:
  - source
  - literature
created: "2026-08-31"
author: "Author Name"
url: "https://..."
type: paper                    # paper | book | video | article | course
inspired: "[[Dopamine Prediction Error]]"  # Links to Permanent Notes it inspired
---
```

## 3. Permanent Note

**Folder**: `20_Zettelkasten/`
**Role**: Atomic knowledge node = knowledge graph node. Carries both knowledge structure and learner state.
**Learning metadata**: All fields

```yaml
---
id: "202608311432"              # Timestamp ID
title: "Dopamine signals prediction error"
tags:
  - permanent
  - neuroscience
created: "2026-08-31"
up: "[[Neuroscience MOC]]"      # Parent MOC
related: "[[Reward Learning]]" # Semantic peers

# --- Knowledge Structure (stable, set at creation) ---
prerequisites: "[[Synapse]]"   # DAG edges (source = prerequisite, target = this note)
difficulty: 3                  # Estimated difficulty 1-5
concept_type: "claim"          # claim | definition | process

# --- Learner State (auto-updated by system, session-level batch sync) ---
mastery: 0.1                   # BKT mastery probability 0-1
learning_state: "pending"     # pending → in_progress → reviewed → mastered
last_reviewed: ""              # ISO date of last review
next_review: ""                # ISO date of next scheduled review
review_count: 0                # Total review count
ease_factor: 2.5               # FSRS parameter (calibrated over time)
---
```

### Frontmatter Field Ownership

| Field | Owner | Update frequency |
|-------|-------|-----------------|
| id, title, tags, created | User | Once at creation |
| up, related, prerequisites | User | Rarely (restructuring) |
| difficulty, concept_type | User/AI | Occasionally |
| mastery, learning_state | System | Per review session |
| last_reviewed, next_review | System | Per review session |
| review_count, ease_factor | System | Per review session |

## 4. MOC (Map of Content)

**Folder**: `30_MOCs/`
**Role**: Structure index = learning domain. Aggregates child mastery, carries learning goals.
**Learning metadata**: aggregate_mastery, child_count, goal, target_date

```yaml
---
id: "202608311433"
title: "Neuroscience MOC"
tags:
  - moc
created: "2026-08-31"
up: "[[Science MOC]]"          # Can nest

# --- Learning Domain Metadata ---
aggregate_mastery: 0.0         # Average mastery of child nodes (system-calculated)
child_count: 0                  # Number of child Permanent Notes
goal: "PMP 备考 - 神经科学基础"
target_date: "2026-12-01"
---
```

## Knowledge Flow

```
Fleeting → process(1-2d) → Literature → distill → Permanent → aggregate → MOC
  ↑ new idea                                    ↑ atomic node   ↑ learning domain
```

## Link Conventions

- `[[Note Name]]`: Obsidian bidirectional link, refers to filename (without .md)
- `prerequisites`: Links to notes that must be mastered before this one (DAG edges)
- `related`: Links to semantically related peers (not for path ordering)
- `up`: Link to parent MOC (belongs_to edge)
- `inspired`: Literature Note → Permanent Note it inspired

## ID System

- Format: `YYYYMMDDHHmm` (e.g., `202608311430`)
- Unique by nature of timestamp
- Sorts chronologically
- Generated by Obsidian Templates plugin: `{{date:YYYYMMDDHHmm}}`
